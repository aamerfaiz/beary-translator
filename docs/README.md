# docs

Source material for this project. **This folder is the source of truth** for
all vocabulary and grammar in the app.

| File | What it is |
|---|---|
| `Dictionary.PDF` | Beary–Kannada–English Lexicon (*Nigantu*), Karnataka Beary Sahitya Academy, 2017. 752 pages of entries in four columns. |
| `PronunciationandStuff.PDF` | The Lexicon's front matter: Preface, phonology and pronunciation key, Editorial, Member Secretary's note. |
| `RELEASE-NOTES.md` | What was extracted, how, and what is known to be imperfect. |

The app never displays Kannada script. The Kannada columns of the Lexicon are
used during extraction only as a positional reference for repairing four
misprinted pages; see `RELEASE-NOTES.md`.
